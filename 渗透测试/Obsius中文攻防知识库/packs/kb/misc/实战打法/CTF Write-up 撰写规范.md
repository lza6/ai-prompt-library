# CTF Write-up 撰写规范

用于赛题解决后产出**可直接交付**的 WP（给队友复核、给主办方验收）。与知识库手册的分工：手册写「下次遇到怎么判」，WP 写「这一次怎么解」——**两者的写作规范不通用**，不要把 WP 的叙述方式带进 kb 手册（手册禁止单题复现）。

## 0. 判据速查

| 现状 | 动作 |
|---|---|
| 刚打完题，会话里全是零散输出 | 先收集产物，再一次性成文（§1） |
| 有多个解法 | 只留一条最干净的路径 |
| 解题过程有大量死路 | 除非死路本身是关键转折，否则删掉 |
| 代码是分段的 | 合并成一段「从题目数据到打印 flag」的完整脚本 |
| 用户要求打码 | 只有明确要求时才隐去 flag |

## 1. 收集产物

成文前把这三类东西收齐，否则写到一半要回头翻会话：

1. **赛题元数据**——题名、赛事、分类、难度、分值、flag 格式。
2. **解题产物**——exploit 脚本、payload、截图、关键命令输出。
3. **时间线**——走过的关键步骤、死路、转折点。

```bash
# 扫解题脚本与产物
find . -name '*.py' -o -name '*.sh' -o -name 'exploit*' -o -name 'solve*' | head -20
# 找输出文件里的 flag
grep -rniE '(flag|ctf|eno|htb|pico)\{' . 2>/dev/null
```

## 2. 交付模板

文件名用 `writeup.md` 或 `writeup-<题名>.md`。

````markdown
---
title: "<题名>"
ctf: "<赛事名>"
date: YYYY-MM-DD
category: web|pwn|crypto|reverse|forensics|osint|malware|misc|ai-ml
difficulty: easy|medium|hard
points: <分值>
flag_format: "flag{...}"
author: "<你的名字或队伍>"
---

# <题名>

## 摘要

<1-2 句：这题是什么、核心手法是什么。直说。>

## 解题

### 步骤 1：<动作>

<用 3-8 行短句说明关键观察。直说。>

```python
<一段完整脚本：从题目给的数据一路跑到打印最终 flag>
```

### 步骤 2：<动作>（可选）

<只有在第二个短步骤确实提升可读性时才加，例如把核心观察与最终验证分开。>

## Flag

```
flag{example_flag_here}
```
````

## 3. 硬性要求

| # | 要求 | 为什么 |
|---|---|---|
| 1 | 总步骤数控制在 1–3 步 | 读者要快速复核，不是读长文 |
| 2 | 代码只留**一段最小的完整解题脚本** | 分段代码逼读者自己拼，等于没写 |
| 3 | 禁止把「还原密钥」「推密钥」「解密」拆成三段半截代码 | 这是最常见的坏写法 |
| 4 | 脚本必须**从题目数据开始、到打印 flag 结束** | 可复现的唯一判据 |
| 5 | 不写长背景介绍 | 与解题无关 |
| 6 | 死路只在「它是关键转折」时保留 | 否则是噪音 |
| 7 | 多个解法只留一条 | 两条路径让读者不知道信哪个 |
| 8 | 除用户明确要求，**不打码 flag** | 打码后无法验证 |

## 4. 定稿前检查表

- [ ] **元数据齐全**——题名、赛事、日期、分类、难度、分值、作者都填了
- [ ] **flag 处理符合要求**——除非用户要求打码，否则保留真实 flag
- [ ] **步骤可复现**——读者照着做能重现
- [ ] **代码能跑**——import 齐全、变量名正确、有关键注释
- [ ] **无敏感数据**——没有真实凭据、API key、内部基础设施细节
- [ ] **长度克制**——够短，能快速复核
- [ ] **标注工具版本**——行为依赖版本时必须写
- [ ] **注明协作与引用**——队友、参考过的 WP、关键工具
- [ ] **格式统一**——标题层级一致、代码块带语言标签

## 5. 该做与不该做

**该做**

- 解释到「够快速验证」为止
- 只给一条完整路径，不给多个备选
- 给一段跑到最终 flag 的完整脚本
- 贴真实输出（太长可截断）证明方法有效
- 代码块标语言（`python`、`bash`、`sql`）
- 主路径前置，读者能立刻验证

**不该做**

- 直接贴原始终端输出而不解释
- 贴若干半截代码让读者自己拼最终解
- 定稿里留占位符
- 写与解题无关的枝节
- 假设读者了解这题的具体环境
