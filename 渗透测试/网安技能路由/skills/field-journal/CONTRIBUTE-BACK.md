# 经验贡献指南

## 如何贡献你的实战经验

在使用本技能路由包完成任务后，你可以将经验贡献回社区。

### 方式 1: PR 贡献（推荐）

1. Fork 本仓库
2. 在 `skills/field-journal/` 下新建经验文件
3. 文件名格式: `YYYY-MM-DD_场景描述.md`
4. 按 `_template.md` 模板填写
5. 更新 `_index.md` 添加索引
6. 提交 PR

### 方式 2: Issue 贡献

在 GitHub Issue 中描述你的踩坑经历，维护者会帮你整理成经验文件。

### 经验文件要求

- **必须**: 按模板格式填写
- **必须**: 包含可复现的步骤或关键代码
- **必须**: 脱敏处理（去掉真实 IP、域名、密码等）
- **建议**: 标注难度和耗时
- **建议**: 标注是否需要更新路由或工具索引

### 安全要求

- 不要包含真实的漏洞利用代码（仅 PoC 框架）
- 不要包含未公开的 0day 信息
- 不要包含目标的敏感信息
- 使用占位符替换真实值: `{target_ip}`, `{username}` 等
