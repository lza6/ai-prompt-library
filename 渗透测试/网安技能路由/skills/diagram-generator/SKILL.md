# 图表生成

## 适用场景

- 从自然语言生成 Mermaid / Graphviz / PlantUML 图表
- 攻击路径图、数据流图、架构图、状态机

## 支持的图表类型

| 类型 | 工具 | 示例场景 |
|------|------|----------|
| 流程图 | Mermaid | 攻击流程、工作流 |
| 架构图 | Mermaid/Graphviz | 系统架构 |
| 时序图 | Mermaid | 请求流程 |
| 状态图 | Mermaid/PlantUML | 协议状态 |
| 类图 | PlantUML | 代码结构 |
| 网络拓扑 | Graphviz | 网络架构 |

## 使用方式

描述你想要的图表 → AI 生成代码 → 渲染为图片
