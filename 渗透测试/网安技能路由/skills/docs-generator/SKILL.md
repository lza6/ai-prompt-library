# 技术文档/报告生成

## 适用场景

- 逆向分析报告
- 渗透测试报告
- CTF writeup
- 签名逆向报告
- 架构文档

## 报告类型

| 类型 | 模板 |
|------|------|
| 逆向报告 | 分析目标、方法、发现、代码片段 |
| 渗透报告 | 范围、发现、风险评级、修复建议 |
| CTF writeup | 题目、思路、解题步骤、flag |
| 技术文档 | 架构、接口、使用说明 |

## 输出格式

- Markdown（默认）
- 可导出为 PDF / HTML
