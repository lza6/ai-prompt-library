# 跨版本符号迁移

## 适用场景

- 有旧版符号（PDB/调试信息），迁移到新版
- 程序更新后批量迁移函数名
- 缺 PDB 时推导符号

## 工具链

| 工具 | 用途 |
|------|------|
| BinDiff | 二进制对比（IDA 插件） |
| Ghidriff | Ghidra 二进制对比 |
| Diaphora | IDA 对比插件 |
| DeepDiff | 结构化数据对比 |

## 工作流程

1. 分析旧版（有符号）和新版（无符号）
2. 使用对比工具匹配函数
3. 迁移函数名和注释
4. 验证匹配准确性
