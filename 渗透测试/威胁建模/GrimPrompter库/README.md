# Grim Prompter 威胁建模提示词库

> jmanico/grim-prompter（MIT）完整库 339 篇：面向 AI 编码智能体的威胁建模提示词集合。

- `quick/`（36）：按领域快速威胁建模（API/AI-ML/区块链/批处理工作流等）
- `deep/`（252）：六阶段深度建模（范围与证据→系统建模→威胁分析→挑战合并→处置验证）
- `methods/`（29）：STRIDE/PASTA/LINDDUN/攻击树/攻击图等具体方法
- `helpers/`（5）：架构选择器/方法选择器/模型挑战者等辅助提示词

本分类的 [模型技能](../模型/模型.md) 即调用本库运行；此处收录完整库原文。
