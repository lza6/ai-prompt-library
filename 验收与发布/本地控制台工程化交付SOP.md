# 本地控制台工程化交付 SOP

> 来源：SeedanceAI 控制台 v12 终局审计（2026-11-11，3 轮独立审查至 Approve）。
> 适用于「单用户 / 本机 / Python 标准库 + 原生 JS」的 Web 控制台，也可裁剪后用于同类内部工具。

## 1. 适用范围

- 本机运行、无鉴权、无公网部署的内部工具；
- 数据是 JSONL/JSON 文件，进程不止一个（控制台 + worker + sidecar）；
- 前端零构建、零依赖，靠原生 JS。

## 2. 交付前 8 步门禁

```bash
python tools/run_checks.py --e2e --coverage
```

1. unittest（tools/tests），**并断言用例数下限**——收集为 0 也要红；
2. pytest 全量（unittest 是它的子集，pytest 能收到 unittest 收不到的 pytest 风格文件）；
3. 对比度（亮/暗）；
4. JS 语法 / Python 编译；
5. 覆盖率不低于基线（不伪造 80%）；
6. 浏览器 E2E（路由 × 视口 + 断连 + 骨架 + pageerror）；
7. UI 截图验收（逐页截图 + 控件盘点 + 安全点击）；
8. 只读压测（≤10 并发、≤60s、0 错误、p99 ≤ 500ms）。

## 3. UI 验收方法（按钮到底能不能按成功）

- **截图要逐页**：每路由 × 亮/暗 × 桌面/移动；人工看图找"竖排单字、行高爆炸、徽章裁切、空态拉满"。
- **控件要盘点**：导出可见 `button/a/input/select/textarea`，检查无文字无 aria 的按钮、无说明的禁用按钮、无标签的输入。
- **点击分级**：只点无副作用（主题/帮助/页签/筛选/搜索/复制/勾选）；危险动作只拦截 `dialog` 记录文案后 `dismiss()`。
- **别用 API 做"参数校验"**：POST 可能有副作用（真实案例：`target=1, workers=99` 被后端夹到 16 并真的起了一轮任务）。校验只用必然 400 的输入。
- **轮询重绘会吃掉用户操作**：勾选/输入在 6s 重绘后必须恢复。

## 4. 多进程账本的四条纪律

1. 唯一真源只一个（`accounts.jsonl`），历史快照文件不再读；
2. 所有写者（控制台、worker、sidecar）共用一把跨进程锁（Windows `msvcrt` / POSIX `flock`）；
3. 读-合并-写必须整段持锁；临时文件带 pid，`os.replace` 原子替换；
4. 局部更新用"按 key 覆盖字段"（`update_write`），不要用"权威度排序合并"——失败结果往往没有更新时间，会被旧记录压掉。

## 5. 错误与状态

- 错误走持久条（标题/原因/下一步/重试/复制详情），toast 只报成功；
- 断连不得把空数组渲染成 0（假 0）；显示"已过期 + 上次成功时间"；
- 请求必须有超时，且**按接口设**：慢接口（验活/建箱/启动）60–120s，普通接口 8s；
- 日志接口有单次上限时，游标按实际返回条数推进；文件轮转后要能回退重读。

## 6. 证据与文档

- `policy.md` 写死数值；`test_ledger.md` 记套件与结果；`evidence/<TASK>.json` 记命令/退出码/输出；
- `workflow_status.md` 记任务图、状态、问题、停止条件；
- 变更报告 HTML 附 6 部分 + 自测题（≥80% 通过）；
- 交接文档写清：怎么起、怎么验、怎么排障、已知限制。

## 7. 审查循环

- 独立只读子代理，最多 3 轮；**主控必须逐条复核**——子代理会在你改文件期间读取，结论可能过时；其运行环境也可能缺依赖。
- 每轮只修 P0/P1，修复必须带回归测试；P2 记录取舍。
- 最终 Verdict 为 Approve 才能结案；未 Approve 必须披露。

## 8. 常见坑（本项目真实踩过）

| 坑 | 症状 | 修法 |
| --- | --- | --- |
| 复选框没 `stopPropagation` | 勾选即弹详情，批量功能假可用 | 单元格截断冒泡 |
| 后端不校验、前端校验 | API 能起空任务/越界被静默夹断 | 前后端同判据 |
| 巡检写历史快照文件 | 续期 Cookie 全部丢失 | 写唯一真源 |
| 锁泄漏 | 409 后巡检永久静默 | 返回前 release，用例断言 |
| 固定 `.tmp` | 并发写产生半行 | pid 临时文件 + 锁 |
| 8s 超时打慢接口 | 假超时、重复建箱 | 按接口超时 |
| E2E 只听 console | 未捕获异常仍判绿 | 加 `pageerror` |

## 9. 不适用

本 SOP 刻意不含：鉴权体系、反向代理、Prometheus/OTel、消息队列、CDN、容器编排。单用户本机工具引入这些属于过度设计；若将来公网部署，另立任务。
