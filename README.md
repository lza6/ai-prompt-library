# 提示词库（Prompt Library）

个人 AI 工作流提示词与 SOP 知识库：覆盖全栈开发、代码审查、项目管理、交付验收、UI/UX、逆向工程方法论等场景。所有内容均为可复用的提示词模板与经验总结，按中文分类目录组织，可在本页索引中快速定位。

## 目录结构

```
提示词库/
├── 全栈语言系列/    # 各语言与专项技术提示词
├── UI设计/          # 前端界面、视觉与体验设计（含 87 个设计/动效技能）
├── 渗透测试/        # 安全测试与自动化渗透（含 806 个安全技能，按 22 个子类归档）
├── 文档生成/        # PRD 与技术文档
├── 工作流与执行/    # 任务执行、断点续作、元提示词（含 187 个 Agent 工程技能）
├── SaaS交付与质量/  # SaaS 全栈交付与项目质量
├── 代码审查/        # 代码审查与安全审计
├── 架构与专项/      # 后端架构、数据库、容器
├── 逆向方法论/      # APK/JS 逆向与网关对接通用方法论（含 123 个逆向技能）
├── 文案创作/        # 去 AI 味写作技能（15 个）
├── 营销与电商/      # 营销技能（53 个）
├── 视频创作/        # 视频生成/剪辑/过审技能（31 个）
└── 产品经理/        # 产品视角与思维技能（16 个）
```

## 使用说明

- 文件名即主题，`.txt` / `.md` 均为纯文本提示词，可直接复制到任意 LLM 对话或 Agent 系统中使用。
- 同名多版本（如 1.0 / 2.0 / 3.0）为迭代关系，优先使用最新版本。
- 部分提示词为英文或法文原文，使用时保持原文即可。
- 各分类下的技能子目录为第三方开源技能打散重编版，SKILL.md 原文未改动；来源与许可见下方 SOURCES 表。
